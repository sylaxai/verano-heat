VERANO HEAT is an original open-world crime game set in Puerto Verano, a sun-soaked coastal city of pastel towers, palm avenues, a beach and Marina Azul. You play Rico Vega, a wheelman working for fixer Marisol "La Sol" Duarte and dock boss Eladio Paz, across a 4-mission story chain: steal a marked coupe, run a timed package, hold three wanted stars and vanish, then clear the rival Los Brasa crew out of the marina in a shootout and escape. The city runs on live systems — lane-following traffic, strolling and fleeing pedestrians, stealable cars, a 1–5 star wanted system with pursuing police (sirens, flashing lights, rams and on-foot busts), hitscan combat, a full HUD with a live minimap, procedural WebAudio sound, and localStorage saves. Controls: WASD/arrows to move and drive, mouse to look and aim, Shift to sprint, E to steal/enter/exit cars, left click to shoot, N for the next job, Esc/P to pause.

## Run it

```sh
node serve.ts
```
then open http://localhost:8080 in a desktop browser. (Or serve the game/ folder with any static file server.)
